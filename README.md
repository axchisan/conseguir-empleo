# Conseguir Empleo con Claude 🧑‍💼

Un asistente que te ayuda a **conseguir trabajo**. Claude:

- busca ofertas en LinkedIn y Computrabajo;
- adapta tu hoja de vida para cada tipo de cargo;
- se postula por ti y responde las preguntas de filtro con tus datos reales;
- lleva todas tus postulaciones en un panel web;
- revisa tu correo para avisarte de entrevistas;
- te prepara para cada entrevista.

No necesitas saber programar: **Claude lo configura todo** y te pide solo lo necesario.

## Qué necesitas

- Un computador (Mac, Windows o Linux).
- **[Claude Code](https://claude.com/claude-code)**, con un plan Pro o superior de Claude.
- Tu hoja de vida actual, en PDF o Word. Si no tienes, la hacen juntos.
- *Opcional, pero recomendado:*
  - la extensión **Claude en Chrome**, para que pueda postularse por ti;
  - los conectores de **Gmail** y **Google Calendar** en claude.ai, para revisar respuestas y agendar entrevistas.

## Cómo empezar (3 pasos)

1. **Descarga el proyecto.** Puedes hacerlo de dos formas:
   - Con el botón verde **Code → Download ZIP**. Descomprímelo donde quieras.
   - O desde una terminal:
     ```bash
     git clone https://github.com/axchisan/conseguir-empleo.git
     ```
2. **Abre Claude Code en esa carpeta.** En la terminal:
   ```bash
   cd conseguir-empleo
   claude
   ```
3. **Escríbele:**
   > Hola, quiero conseguir trabajo. Configura todo.

Claude revisa qué falta, instala lo necesario y crea tu base de datos gratis en Neon. Después te pide tu hoja de vida y te hace unas preguntas: qué trabajo buscas, cuánto quieres ganar y desde cuándo puedes empezar. Con eso genera tus CVs adaptados y te deja el panel listo.

## Después, solo pídele cosas

- "Busca ofertas nuevas de hoy"
- "Postúlame a las mejores"
- "Revisa mi correo, ¿me respondió alguien?"
- "Me llamaron para entrevista el jueves a las 10, agéndala y prepárame"
- "Ayúdame a responderle a esta reclutadora" (y le pegas la captura del WhatsApp)
- "Abre mi panel"

## Tu información es privada

Tus datos personales, tu CV, tus certificados y tus claves se quedan **solo en tu computador** y en tu base de datos. El archivo `.gitignore` impide que se suban a GitHub.

Claude sigue estas reglas:

- **Nunca inventa experiencia.**
- **Nunca escribe tus contraseñas:** tú inicias sesión en cada sitio.
- **No envía correos a empresas sin tu permiso.**
